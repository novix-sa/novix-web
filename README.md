# novix-web

Sitio web de Novix (HTML estático), publicado con GitHub Pages desde la rama `main`.

- Sitio: https://novix-sa.github.io/novix-web/ (más adelante, https://newsite.novix.com)
- Se edita con Claude, en la pestaña **Code** de la app de escritorio. Claude trae lo último del equipo, muestra los cambios en su navegador y, si le decís que sí, los publica. Las instrucciones que sigue están en [CLAUDE.md](CLAUDE.md).

## Empezar (una sola vez)

1. Tener cuenta de GitHub y aceptar la invitación a este repositorio.
2. Crear una carpeta vacía llamada `novix-web` en tu carpeta de usuario (no en Escritorio ni en Documentos).
3. Abrir la app de Claude → **Code** → elegir esa carpeta y pedirle: "Configurá esta carpeta con el repositorio https://github.com/novix-sa/novix-web.git (rama main), leé CLAUDE.md y hacé la configuración de primera vez."

## Día a día

Abrí Claude → **Code** → carpeta `novix-web` y pedí lo que quieras cambiar. Cuando te guste cómo se ve, Claude te pregunta si lo publica.
